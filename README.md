# IPL Cricket Score Prediction

## 📖 Project Overview
This project predicts the final score of an IPL cricket match using machine learning algorithms. The model takes into account various match parameters like current runs, wickets, overs, recent performance, and team combinations to forecast the final total.

## 🎯 Business Problem
Accurate score prediction in cricket helps:
- Teams in strategic decision making
- Broadcasters for audience engagement
- Fantasy sports platforms
- Betting industry insights
- Fan engagement and analysis

## 📊 Dataset
The dataset contains ball-by-ball data from IPL matches with features including:
- Match metadata (date, teams)
- Current match status (runs, wickets, overs)
- Recent performance (last 5 overs)
- Derived features (run rate, balls remaining, etc.)
